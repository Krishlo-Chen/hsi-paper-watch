## 待人工确认

### 1. AHA! Animating Human Avatars in Diverse Scenes with Gaussian Splatting
- 论文链接：https://arxiv.org/abs/2511.09827
- 评审页：https://openreview.net/forum?id=uZH0kBz5fk
- 代码链接：https://github.com/miraymen/aha_codebase
- 首次公开时间：arXiv 2025-11-13；OpenReview 页面在 2026-02-11 前后仍可见更新痕迹
- 相关性判断：边缘相关
- 研究问题概述：关注如何把可驱动的人体 avatar 放入 3D Gaussian Splatting 场景中完成走动、坐下等场景内动画与交互。
- 方法亮点：把人体与场景统一表示为高斯，并用高斯对齐的运动模块和人-场景 refinement 来改善放置与接触合理性。
- 代码状态：可见官方关联仓库，但当前 README 仅写明 "Coming Soon"，仍属于占位发布。
- 待确认原因：更偏向场景内 avatar 动画 / 渲染，而不是核心 HSI 生成或重建；公开实现也还不完整。

### 2. FunREC: Reconstructing Functional 3D Scenes from Egocentric Interaction Videos
- 论文链接：https://arxiv.org/abs/2604.05621
- 项目页：https://functionalscenes.github.io/
- 代码链接：本次未核实到可公开访问的官方仓库
- 首次公开时间：arXiv 2026-04-08
- 相关性判断：边缘相关
- 研究问题概述：从第一视角交互视频中重建带可动部件和运动学参数的功能性 3D 场景。
- 方法亮点：利用真实人-场景交互过程恢复 articulated parts、其运动轨迹与静态/动态几何，并输出可用于仿真和机器人执行的场景表示。
- 代码状态：项目页很完整，并显示有 Code / Data 入口，但本次未验证到公开官方代码仓库。
- 待确认原因：它更像“由交互驱动的功能场景重建”，核心目标不是直接建模或生成 HSI；如果后续公开代码与数据，值得继续跟进。

## 趋势观察

这两天新冒出来、但尚不适合升格为“确认新增”的项目，明显更偏向两条支线：一条是场景内 avatar 动画 / 渲染，另一条是利用交互线索做功能场景重建。相比直接生成或重建 human-scene interaction，本轮公开结果更常把“交互”作为中间约束或监督信号来服务更大的场景建模任务。

从代码开放情况看，公开信号依然偏早：要么只有占位仓库，要么项目页已经挂出 Code 按钮但还没有可核实的官方实现。这说明近期值得重点盯的是“项目页已上线但仓库尚未实装”的条目，而不是单看论文是否刚公开。
