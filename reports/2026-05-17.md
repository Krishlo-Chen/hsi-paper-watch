# HSI 每日追踪报告 — 2026-05-17 JST

## 新发现

### 1. UniCon3R: Contact-aware 3D Human-Scene Reconstruction from Monocular Video
- 论文链接: https://arxiv.org/abs/2604.19923
- 项目链接: https://surtantheta.github.io/UniCon3R/
- 代码链接: https://github.com/surtantheta/UniCon3R
- 发布时间或首次公开时间: 2026-04-21（arXiv）
- 研究问题概述: 面向单目视频的在线 4D 人体-场景重建，重点解决人物悬浮、穿模等物理不合理问题。
- 方法亮点: 把人体-场景接触从“附加预测结果”变成“内部纠正信号”，用接触提示直接修正人体重建潜变量。
- 代码状态总结: 官方仓库已公开并明确对应论文，但 README 仍写明完整代码、权重和推理脚本将陆续补齐。
- 为什么值得关注: 它把“接触”从评测指标推进成了重建主干的一部分，是 HSI reconstruction 里很清晰的方法升级。

### 2. Human3R: Everyone Everywhere All at Once
- 论文链接: https://arxiv.org/abs/2510.06219
- 项目链接: https://fanegg.github.io/Human3R/
- 代码链接: https://github.com/fanegg/Human3R
- 发布时间或首次公开时间: 2025-10-07（arXiv）
- 研究问题概述: 从单目视频统一恢复多人 SMPL-X、稠密场景几何和相机轨迹，强调实时、单阶段的人体-场景联合重建。
- 方法亮点: 基于 CUT3R 做参数高效迁移，把以往分散的人体、场景、相机估计并到一个前馈框架里。
- 代码状态总结: 官方仓库已公开，README 提供安装、模型下载、推理、评测和训练入口，完整度在本次新发现里最高。
- 为什么值得关注: 它代表了 HSI reconstruction 从多阶段优化管线走向统一前馈模型的趋势，工程可复用性很强。

### 3. GenHSI: Controllable Generation of Human-Scene Interaction Videos
- 论文链接: https://arxiv.org/abs/2506.19840
- 项目链接: https://kunkun0w0.github.io/project/GenHSI/
- 代码链接: 未确认公开官方仓库
- 发布时间或首次公开时间: 2025-06-24（arXiv）；WACV 2026 页面已公开
- 研究问题概述: 从单张场景图像、人物参考图和文本任务描述生成长时段、可控的人体-场景交互视频。
- 方法亮点: 借鉴电影制作流程，把长视频 HSI 生成拆成脚本拆解、3D-aware 预演关键帧、视频动画三阶段，尽量不依赖昂贵训练。
- 代码状态总结: 公开项目页存在 GitHub 按钮，但本次未检索到可验证的官方公开仓库，暂按“未开源”处理。
- 为什么值得关注: 它把 HSI 从 3D 动作/姿态层面推进到长视频生成层面，说明任务边界正在向叙事型视频合成扩展。

## 趋势观察

- 这次可靠新增同时覆盖了重建和生成两端，但重建方向更集中，尤其是“前馈化”和“接触约束内生化”两个趋势很明显。
- `Human3R` 与 `UniCon3R` 说明 human-scene reconstruction 正在从重优化管线转向统一在线模型，其中 `UniCon3R` 进一步强调接触信号不只用于打分，而要反向修正人体估计。
- 代码开放情况仍然不均衡：重建类工作更容易看到可运行仓库，而视频生成类如 `GenHSI` 仍以论文和项目页先行，公开实现滞后。
