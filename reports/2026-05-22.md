# HSI 每日追踪报告 — 2026-05-22 JST

## 新发现

### GRAFT: Geometric Refinement and Fitting Transformer for Human Scene Reconstruction
- 论文链接：https://arxiv.org/abs/2604.19624
- 项目链接：https://pradyumnaym.github.io/graft/
- 代码链接：https://github.com/pradyumnaym/graft
- 发布时间 / 首次发现时间：arXiv 于 2026-04-21 首次公开；本次于 2026-05-22 确认为新增
- 研究问题概述：该工作聚焦单张图像下的人体-场景重建，核心目标是在保持前馈速度的同时，显式修正人与场景之间的接触关系，减少悬浮和穿插问题。它属于核心 HSI reconstruction 方向，而不是一般的人体网格恢复。
- 方法亮点：GRAFT 将几何拟合过程“摊平”为可学习的迭代修正，用 body-anchored tokens 与 Geometric Probes 编码局部场景几何关系，并通过轻量 Transformer 反复预测 interaction gradients。除了端到端重建模式外，它还能作为几何先验插到现有方法后面做 contact-aware refinement。
- 代码状态总结：已确认官方项目页和官方 GitHub 仓库均已公开，但 README 仍把 code release 标为 pending，当前仓库更像正式占位仓而非完整可复现实装。
- 为什么值得关注：它代表 2026 年 HSI reconstruction 的一个清晰趋势，即把“物理合理的接触修正”从慢速优化迁移到快速前馈模块，对真实图片、多人场景和后续插件式增强都很有价值。

### InHabit: Leveraging Image Foundation Models for Scalable 3D Human Placement
- 论文链接：https://arxiv.org/abs/2604.19673
- 项目链接：https://virtualhumans.mpi-inf.mpg.de/inhabit/
- 代码链接：https://github.com/nibox/Inhabit
- 原因说明：该工作明确生成大规模 3D human-scene interaction 数据，并验证这些数据能提升 HSI reconstruction 与 contact estimation，因此和 HSI 高度相关；但它的主任务表述仍更偏“可扩展的人体放置 / 数据生成”，而不是直接的人体-场景交互生成或重建基准任务。
- 当前判断：暂列待人工确认。另一个保守因素是虽然官方项目页、仓库和数据入口都已出现，但仓库 README 仍将 code release 与 dataset release 标记为待发布。

## 趋势观察

- 今天新增候选明显偏向 reconstruction-side 的“接触合理性”和“几何修正”，而不是纯文本驱动生成。
- 候选项目越来越常见“官方项目页 + 官方 GitHub 仓库先开放、完整代码后补”的发布节奏，公开信号变强了，但真正可复现性仍需谨慎区分。
- 与 HSI 边界相邻的方向正在增多，尤其是 human placement、synthetic data generation、real2sim 与 contact-aware refinement，这类工作后续可能会继续推动 HSI reconstruction 的数据和评测升级。
